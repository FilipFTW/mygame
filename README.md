# mygame
My game is about racing. So far, I’ve created a basic car with a suspension system, a menu, a small prototype map to be used at the start of the game, and a track that is still a work in progress.
Next, I plan to add a checkpoint system, vehicle tuning, opponents, and a city where the races will take place.
Currently, the game is controlled solely using the W, A, S, and D keys, but I will add other controls in the future.
I can't really say much more about the game, because that's about all I've done so far.
For the game to run you need to have the .exe, .pck, and libterrain.windows.debug.x86_64.dll in the same folder, then click the .exe file.
Have fun
