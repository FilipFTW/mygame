# mygame
My game is about racing. So far, I’ve created a basic car with a suspension system, a menu, a small prototype map to be used at the start of the game, and a track that is still a work in progress.
Next, I plan to add a checkpoint system, vehicle tuning, opponents, and a city where the races will take place.
Currently, the game is controlled solely using the SPACE, W, A, S, and D keys, but I will add other controls in the future.
W - accelerate
A - steer left
S - brake/reverse
D - steer right
SPACE - handbrake
I can't really say much more about the game, because that's about all I've done so far.
In the latest update I added a new scene, the city map, with only roads for now, i had a hard time making the script for the roads to work but in the end I finally made it working
I changed the cars physics, the car can only steer when the front tires are touching the ground. The car can now drift at high speeds by pressing SPACE
For the game to run you need to have the .exe, .pck, and libterrain.windows.debug.x86_64.dll in the same folder, then click the .exe file.
Have fun
